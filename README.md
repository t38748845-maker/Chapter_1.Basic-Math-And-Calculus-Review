1. Number Theory

Definition:
 Number theory is the branch of mathematics that studies numbers and their properties.

Types of Numbers:

Natural Numbers (N): 1, 2, 3, 4, ...
\tWhole Numbers (W): 0, 1, 2, 3, ...
  Integers (Z): ..., -3, -2, -1, 0, 1, 2,...
  Rational Numbers (Q): Numbers that can be written as a fraction.
  Irrational Numbers: Cannot be written as a            fraction (√2, π).
  Real Numbers (R): Rational + irrational numbers.
Example
7 → Natural number
-4 → Integer
3/5 → Rational number
√5 → Irrational number

2. Order of Operations (PEMDAS/BODMAS)

Always solve expressions in this order:
Parentheses
Exponents
Multiplication and Division
Addition and Subtraction
Example
Step 1:
4² = 16
Step 2:
16 − 6 = 10
Step 3:
3 × 10 = 30
Step 4:
5 + 30 = 35
3. Variables
A variable is a symbol representing an unknown value.
Example
x = 5
Then
2x + 3
= 2(5) + 3
= 13
Variables help describe changing quantities.
4. Functions
A function maps every input to exactly one output.
Notation
f(x)
Example
f(x)=2x+1
If x=4
f(4)=2×4+1=9
Real-life example
Distance = Speed × Time

6. Exponents
An exponent tells how many times a number is multiplied by itself.
Examples
2³ = 2×2×2 = 8

5² =25

10⁰ =1
Rules
a^m × a^n = a^(m+n)

a^m / a^n = a^(m−n)

(a^m)^n = a^(mn)

a^-n =1/a^n
Example
2³×2²=2⁵=32
7. Logarithms
A logarithm is the inverse of an exponent.
If
2³=8
then
log₂(8)=3
Common Logarithms
log₁₀(100)=2

log₁₀(1000)=3
Log Rules
log(ab)=log(a)+log(b)

log(a/b)=log(a)-log(b)

log(aⁿ)=nlog(a)
